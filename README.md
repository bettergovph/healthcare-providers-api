## Requirements

- [Node.js](https://nodejs.org/) (LTS recommended)

- [PNPM](https://pnpm.io/) (required package manager)

- [Nest](https://github.com/nestjs/nest)

## Getting Started

### 1. Clone the repository

```bash
gh repo clone bettergovph/healthcare-providers-api
cd healthcare-providers-api
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Run the development server

```bash
pnpm start:dev
```

## Scripts

- pnpm start:dev — Start the development server
- pnpm build — Build the project for production
- pnpm start:prod — Start the production server
- pnpm lint — Run linting checks
