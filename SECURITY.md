# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in BetterGov.ph Healthcare Providers - API, please report it privately.

- Email: security@bettergov.ph
- Do **not** open a public issue for security concerns.

Please include as much detail as possible, including:

- Steps to reproduce the vulnerability
- Potential impact
- Any suggested mitigation

We will acknowledge your report within 72 hours and work with you to resolve the issue promptly.

Thank you for helping keep BetterGov.ph Healthcare Providers - API secure!
