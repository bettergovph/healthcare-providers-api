# Contributing to BetterGov.ph - Healthcare Providers - API

Thank you for your interest in contributing! Here are some guidelines to help you get started.

## How to Contribute

- Fork the repository and create your branch from `main`.
- Make sure your code follows our style guidelines.
- Write clear commit messages.
- If you are fixing a bug, please include a test that demonstrates the fix.
- For new features, describe your motivation and use cases.

### Local development

Create the file `.env` with the following variables:

```txt
POSTGRES_DB=healthcareapidb
POSTGRES_USER=healthcareapiadmin
POSTGRES_PASSWORD=healthcareapipassword
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

## Pull Requests

- Ensure your branch is up to date with `main`.
- Open a pull request with a clear description of your changes.
- Reference related issues in your PR description.
- Address review comments promptly.

## Issue Reporting

- Search for existing issues before opening a new one.
- Provide a clear and descriptive title.
- Include steps to reproduce, expected behavior, and screenshots if applicable.

## Code Style

- Use consistent indentation and formatting.
- Write descriptive variable and function names.
- Add comments where necessary.

## Community

- Be respectful and constructive in all communications.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping make BetterGov.ph Healthcare Providers - API better!
